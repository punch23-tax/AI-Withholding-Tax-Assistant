# AI Withholding Tax Assistant (AC317)

เว็บไซต์ HTML/CSS/Vanilla JavaScript สำหรับการศึกษาเกี่ยวกับภาษีเงินได้หัก ณ ที่จ่ายของไทย

## วิธีใช้งาน
1. เปิด `index.html` ในเบราว์เซอร์ หรือเผยแพร่ผ่าน GitHub Pages
2. กรอกผู้จ่าย ผู้รับเงิน รายละเอียดธุรกรรม วันที่จ่าย และ VAT
3. กด **วิเคราะห์ภาษี** เพื่อดูข้อมูลที่ยืนยันได้และประเด็นที่ต้องตรวจสอบ
4. ใช้ปุ่มคัดลอกหรือพิมพ์ผลลัพธ์

## Deploy ผ่าน GitHub Pages
1. สร้าง GitHub repository ใหม่ (Public)
2. อัปโหลด `index.html`, `style.css`, `script.js`, `tax-rules.js` ไว้ที่ root ของ repository
3. ไปที่ Settings → Pages → Build and deployment → Deploy from a branch
4. เลือก branch `main`, folder `/(root)` และ Save
5. รอให้ GitHub แสดง URL ของเว็บไซต์

## ข้อจำกัดสำคัญ
- กฎใน `tax-rules.js` เป็น **candidate rules ที่ยังไม่ได้ตรวจสอบวันที่มีผล** ไม่ใช่ฐานกฎหมายที่รับรองแล้ว
- ระบบจงใจ **ไม่สรุปอัตราภาษีหรือยอดสุทธิ** จนกว่าจะยืนยันเงื่อนไขและกฎหมายที่มีผล ณ วันจ่าย
- VAT 7% เป็นตัวเลือกเพื่อคำนวณเชิงคณิตศาสตร์ ไม่ใช่คำยืนยันว่า VAT 7% ใช้กับธุรกรรมใด ๆ
- ไม่มี AI API, backend หรือการเชื่อม Firebase; ข้อมูลไม่ได้ถูกส่งไปยังเซิร์ฟเวอร์
- ไม่มีการทดสอบเทียบคำตอบใบงานต้นฉบับ เพราะไม่ได้แนบสมมติฐานของแต่ละกรณีในคำขอนี้
- กรณีค่าขนส่งสินค้า อัตราเบื้องต้น 1% ต้องตรวจสอบประเภทผู้ให้บริการ เงื่อนไข และข้อยกเว้น
- กรณีซื้อสินค้าพร้อมค่าจัดส่งต้องแยกข้อเท็จจริงและพิจารณาว่าเป็นค่าขนส่งที่แยกต่างหากหรือไม่

## การทดสอบ
เปิดหน้าเว็บและกรอกชุดข้อมูลทดสอบ 10 กรณีตามโจทย์; ตรวจว่าแสดงสถานะต้องตรวจสอบและไม่สร้างอัตราหรือยอดสุทธิที่ไม่มีหลักฐาน

แหล่งอ้างอิงเบื้องต้น: https://www.rd.go.th/3479.html และ https://www.rd.go.th/

**เพื่อการศึกษาเท่านั้น** ควรให้ผู้เชี่ยวชาญตรวจสอบก่อนนำไปใช้จริง


## อัปเดตกฎหมาย 20 พฤศจิกายน 2569
- อัปเดตฐานกฎทั่วไป: ค่าเช่า 5%, บริการ 3%, จ้างทำของ 3%, โฆษณา 2%, ขนส่งสินค้า 1% ตามเงื่อนไขของ ท.ป.4/2528 และฉบับแก้ไข (https://www.rd.go.th/3479.html)
- ข้อ 12/4 ค่าขนส่งสินค้า 1% ไม่รวมค่าโดยสารขนส่งสาธารณะ (https://rd.go.th/3291.html)
- มาตรการ e-Withholding Tax 1% บางกรณีตาม ท.ป.354/2566 ระบุวันสิ้นสุด 31 ธันวาคม 2568; อย่าใช้กับปี 2569 โดยอัตโนมัติ
- VAT ทั่วไป 7% ถึง 30 กันยายน 2570 ตามพระราชกฤษฎีกาฉบับที่ 807 พ.ศ.2569 (https://www.rd.go.th/21221/archive/2026/english.html)
- ฐานกฎนี้แสดงเพียงอัตราทั่วไปเพื่อการศึกษา **ยังไม่ตัดสินสิทธิ/หน้าที่หักจริงและยังไม่คำนวณยอดหัก** จนกว่าจะมีการตรวจสอบข้อเท็จจริง ข้อยกเว้น และกฎหมายย้อนหลังให้ครบ
- ไม่ถือเป็นการตรวจทานกฎหมายทุกฉบับหรือทุกกรณี โดยเฉพาะรายการข้ามประเทศ สัญญาผสม ค่าซื้อสินค้า โรงแรม และภัตตาคาร


## Dashboard UI
หน้าตาใหม่ตามภาพอ้างอิง: เมนูแท็บ ภาพรวม 4 การ์ด สรุปยอด และฟอร์มแยกหน้า โดยยังคงใช้ engine แบบระมัดระวัง ไม่สรุป WHT จนกว่าจะยืนยันเงื่อนไขกฎหมายครบถ้วน


## ปรับปรุงการคำนวณค่าขนส่งสินค้า 1%
- สำหรับผู้จ่ายนิติบุคคลในไทยและผู้รับบุคคลธรรมดา/นิติบุคคลในไทย เมื่อเป็นการรับขนสินค้าโดยไม่มีบริการอื่น และยอดตามสัญญาตั้งแต่ 1,000 บาท ระบบคำนวณ 1% ตามคำสั่ง ท.ป.4/2528 ข้อ 12/4
- กรณีไม่ระบุ VAT แสดงยอดภาษีหัก ณ ที่จ่ายได้ แต่ไม่แสดงยอดสุทธิ
- รายการผสม บริการอื่น ผู้รับต่างประเทศ หรือข้อมูลไม่ครบ ให้ตรวจสอบเพิ่มเติม
- อ้างอิง https://www.rd.go.th/3479.html และ https://www.rd.go.th/39321.html
- โค้ดคำนวณประเภทอื่นยังคงสถานะรอตรวจสอบ ไม่ควรใช้เป็นคำวินิจฉัยภาษี


## แก้ไขค่าขนส่งสินค้า 1%
เลือกค่าขนส่งสินค้า กรอกจำนวนเงิน สถานะผู้จ่าย/ผู้รับ ประเทศ วันที่ VAT และติ๊กช่องยืนยันว่าเป็นการรับขนสินค้าโดยเฉพาะ ระบบคำนวณ 1% เมื่อผ่านเงื่อนไข หากข้อมูลไม่ครบจะแสดงชื่อช่องที่ขาด โปรดตรวจสอบสัญญาและกฎหมายก่อนใช้งานจริง


## ประวัติรายการ (Local Storage)
เมื่อวิเคราะห์ภาษีแล้วกด **บันทึกรายการนี้** เพื่อเก็บข้อมูลธุรกรรมและผลวิเคราะห์ลงเบราว์เซอร์ เปิดแท็บ **ประวัติรายการ** เพื่อค้นหา ดูผล แก้ไข หรือลบ และส่งออก/นำเข้า JSON เพื่อสำรองข้อมูล การดูผลจะคำนวณซ้ำด้วยกฎปัจจุบัน แต่ข้อมูลผลเดิมยังเก็บในประวัติ ข้อมูลไม่ซิงก์ระหว่างอุปกรณ์ ไม่ถูกส่งไป Firebase และอาจหายหากล้างข้อมูลเบราว์เซอร์ อย่าใช้กับข้อมูลส่วนบุคคลจริงที่อ่อนไหวบนเครื่องที่ใช้ร่วมกัน
