# AI Withholding Tax Assistant (AC317)

เว็บไซต์ HTML/CSS/Vanilla JavaScript สำหรับการศึกษาเกี่ยวกับภาษีเงินได้หัก ณ ที่จ่ายของไทย

## วิธีใช้งาน
1. เปิด `index.html` ในเบราว์เซอร์ หรือเผยแพร่ผ่าน GitHub Pages
2. กรอกผู้จ่าย ผู้รับเงิน รายละเอียดธุรกรรม วันที่จ่าย และ VAT
3. กด **วิเคราะห์ภาษี** เพื่อดูข้อมูลที่ยืนยันได้และประเด็นที่ต้องตรวจสอบ
4. ใช้ปุ่มคัดลอกหรือพิมพ์ผลลัพธ์

## Deploy ผ่าน GitHub Pages
1. สร้าง GitHub repository ใหม่ (Public)
2. อัปโหลด `index.html`, `style.css`, `script.js`, `tax-rules.js` ไว้ที่ root ของ repository
3. ไปที่ Settings → Pages → Build and deployment → Deploy from a branch
4. เลือก branch `main`, folder `/(root)` และ Save
5. รอให้ GitHub แสดง URL ของเว็บไซต์

## ข้อจำกัดสำคัญ
- กฎใน `tax-rules.js` เป็น **candidate rules ที่ยังไม่ได้ตรวจสอบวันที่มีผล** ไม่ใช่ฐานกฎหมายที่รับรองแล้ว
- ระบบจงใจ **ไม่สรุปอัตราภาษีหรือยอดสุทธิ** จนกว่าจะยืนยันเงื่อนไขและกฎหมายที่มีผล ณ วันจ่าย
- VAT 7% เป็นตัวเลือกเพื่อคำนวณเชิงคณิตศาสตร์ ไม่ใช่คำยืนยันว่า VAT 7% ใช้กับธุรกรรมใด ๆ
- ไม่มี AI API, backend หรือการเชื่อม Firebase; ข้อมูลไม่ได้ถูกส่งไปยังเซิร์ฟเวอร์
- ไม่มีการทดสอบเทียบคำตอบใบงานต้นฉบับ เพราะไม่ได้แนบสมมติฐานของแต่ละกรณีในคำขอนี้
- กรณีค่าขนส่งสินค้า อัตราเบื้องต้น 1% ต้องตรวจสอบประเภทผู้ให้บริการ เงื่อนไข และข้อยกเว้น
- กรณีซื้อสินค้าพร้อมค่าจัดส่งต้องแยกข้อเท็จจริงและพิจารณาว่าเป็นค่าขนส่งที่แยกต่างหากหรือไม่

## การทดสอบ
เปิดหน้าเว็บและกรอกชุดข้อมูลทดสอบ 10 กรณีตามโจทย์; ตรวจว่าแสดงสถานะต้องตรวจสอบและไม่สร้างอัตราหรือยอดสุทธิที่ไม่มีหลักฐาน

แหล่งอ้างอิงเบื้องต้น: https://www.rd.go.th/3479.html และ https://www.rd.go.th/

**เพื่อการศึกษาเท่านั้น** ควรให้ผู้เชี่ยวชาญตรวจสอบก่อนนำไปใช้จริง
